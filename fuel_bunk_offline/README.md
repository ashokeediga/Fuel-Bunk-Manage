# Fuel Bunk Manager · 100% Offline Python Software
# పెట్రోల్ బంక్ మేనేజర్ · కంప్లీట్ ఆఫ్లైన్ పైథాన్ సాఫ్ట్వేర్

---

## 🇮🇳 తెలుగు వివరణ (Telugu Overview)

ప్రస్తుత ఆన్‌లైన్/క్లౌడ్‌ఫ్లేర్ సాఫ్ట్‌వేర్‌ను (`desktop.html`, `index.html`) **ఏమాత్రం మార్చకుండా, ఎటువంటి డిస్టర్బెన్స్ లేకుండా**, కేవలం ఈ ప్రత్యేక ఫోల్డర్ (`fuel_bunk_offline/`) లో **100% పూర్తి ఆఫ్‌లైన్ సాఫ్ట్‌వేర్‌ను** పైథాన్ మరియు SQLite లో రూపొందించడం జరిగింది.

దీనికి **ఎటువంటి ఇంటర్నెట్ కనెక్షన్ లేదా క్లౌడ్ అవసరం లేదు**. మొత్తం డేటా మీ కంప్యూటర్‌లోనే భద్రంగా `fuel_bunk.db` ఫైల్‌లో స్టోర్ అవుతుంది.

### 🌟 ప్రధాన ఫీచర్లు (Key Features):
1. **ఆటోమేటిక్ ఓపెనింగ్ రీడింగ్స్ ప్రీ-ఫిల్ (Auto Opening Meter Readings)**:
   - పంప్ (Pump 1, 2, 3 CNG) ఎంచుకోగానే, ఆ పంప్ యొక్క **మునుపటి షిఫ్ట్ క్లోజింగ్ రీడింగ్స్ ఆటోమేటిక్‌గా నేటి ఓపెనింగ్ రీడింగ్స్‌గా ఫిల్ అవుతాయి**.
   - అవసరమైతే మాన్యువల్‌గా మార్చుకునే సదుపాయం ఉంది.
2. **మిడ్-షిఫ్ట్ రేట్ చేంజ్ (Mid-Shift Rate Change)**:
   - షిఫ్ట్ మధ్యలో రేటు మారినప్పుడు, ఓపెనింగ్ నుండి మిడ్ రీడింగ్ వరకు రేట్ 1, మిడ్ రీడింగ్ నుండి క్లోజింగ్ వరకు రేట్ 2 లెక్కించే ఫీచర్.
3. **మల్టిపుల్ ఎక్స్‌పెండిచర్స్ (Multiple Dynamic Expenses)**:
   - `+ Add Expense Row` క్లిక్ చేసి ఎన్ని ఖర్చులైనా (కరెంట్ బిల్, డీజిల్, టీ/స్నాక్స్, రిపేర్లు, మొదలైనవి) వివరాలతో ఎంటర్ చేయవచ్చు. ఆటోమేటిక్ టోటల్ క్యాలిక్యులేషన్.
4. **డిజిటల్ పేమెంట్స్ & నెట్ క్యాష్ (Net Cash & Digital Payments)**:
   - Online / UPI / QR ₹, HPCL Fleet OTP ₹, HP Pay ₹, టెస్టింగ్ వివరాలు.
   - అన్నింటి చివరలో **Net Cash ₹** బాక్స్ ఉంటుంది.
   - రియల్ టైమ్ టాలీ బ్యాడ్జ్: Balanced ✅ / Short Cash ⚠️ / Excess Cash ℹ️.
5. **మంత్లీ షిఫ్ట్ క్యాలెండర్ (Monthly Shift Calendar)**:
   - ఆ నెలలో ఎంటర్ చేసినవి ఆకుపచ్చ (🟢 Green), మిస్ అయినవి ఎరుపు (⚠️ Red).
   - డబుల్ ఎంట్రీలు ఉంటే `⚡ Double` సింబల్, రీడింగ్స్ మిస్‌మ్యాచ్ అయితే `⚠️ Mismatch` వార్నింగ్ సింబల్స్ కనిపిస్తాయి.
6. **స్టాక్ పర్చేసెస్ (Inward Stock Register)**:
   - ట్యాంకర్ లారీ వచ్చినప్పుడు పెట్రోల్/డీజిల్/CNG స్టాక్ ఇన్వర్డ్ రికార్డు నమోదు.
7. **1-క్లిక్ డాటాబేస్ బ్యాకప్ & రీస్టోర్ (1-Click Local Backup & Restore)**:
   - ఒక్క క్లిక్‌తో మీ డేటాబేస్ సేఫ్టీ బ్యాకప్ స్నాప్‌షాట్ సేవ్ చేసుకోవచ్చు.

### 🚀 ఎలా రన్ చేయాలి? (How to Run)

ఈ ఫోల్డర్‌లో మీ కోసం సులభమైన **1-క్లిక్ లాంచర్ ఫైల్స్** అందించబడ్డాయి:

#### పద్ధతి 1: డెస్క్‌టాప్ వెబ్ యాప్ (సిఫార్సు చేయబడింది - Recommended)
* `Launch_Offline_Web.bat` ఫైల్ పై **డబుల్ క్లిక్** చేయండి.
* వెంటనే లోకల్ ఆఫ్లైన్ సర్వర్ స్టార్ట్ అయి మీ బ్రౌజర్‌లో ఆధునిక స్క్రీన్ ఓపెన్ అవుతుంది:
  * URL: `http://127.0.0.1:8085`

#### పద్ధతి 2: నేటివ్ విండోస్ GUI యాప్ (Native Desktop Window)
* `Launch_Desktop_GUI.bat` ఫైల్ పై **డబుల్ క్లిక్** చేయండి.
* స్వతంత్ర విండోస్ అప్లికేషన్ విండో ఓపెన్ అవుతుంది (బ్రౌజర్ కూడా అవసరం లేదు).

#### పద్ధతి 3: డెస్క్‌టాప్ షార్ట్‌కట్స్ క్రియేట్ చేయడం
* `Create_Desktop_Shortcut.bat` పై డబుల్ క్లిక్ చేస్తే మీ విండోస్ డెస్క్‌టాప్ స్క్రీన్ పై డైరెక్ట్ షార్ట్‌కట్ ఐకాన్లు క్రియేట్ అవుతాయి.

## 📁 ఫైల్స్ వివరాలు (Project Structure)

| ఫైల్ పేరు | వివరణ |
| :--- | :--- |
| `fuel_bunk.db` | లోకల్ SQLite డేటాబేస్ (అన్ని షిఫ్ట్‌లు, నాజిల్‌లు, ఖర్చులు ఇందులోనే ఉంటాయి) |
| `database.py` | డేటాబేస్ ఇంజిన్ మరియు క్వెరీల నిర్వహణ |
| `offline_server.py` | 100% పైథాన్ బిల్ట్-ఇన్ ఆఫ్లైన్ వెబ్ సర్వర్ |
| `desktop_gui.py` | నేటివ్ విండోస్ Tkinter డెస్క్‌టాప్ యాప్ |
| `main.py` | యూనిఫైడ్ లాంచర్ స్క్రిప్ట్ |
| `import_cloud_data.py` | క్లౌడ్ నుండి పాత డేటాను లోకల్‌గా సింక్ చేసే టూల్ |
| `templates/app.html` | ఆఫ్లైన్ వెబ్ అప్లికేషన్ UI |
| `Launch_Offline_Web.bat` | ఆఫ్లైన్ వెబ్ యాప్ 1-క్లిక్ లాంచర్ |
| `Launch_Desktop_GUI.bat` | ఆఫ్లైన్ డెస్క్‌టాప్ విండో 1-క్లిక్ లాంచర్ |
| `Create_Desktop_Shortcut.bat` | డెస్క్‌టాప్ షార్ట్‌కట్స్ సృష్టించే స్క్రిప్ట్ |
| `backups/` | ఆటోమేటిక్ డేటాబేస్ బ్యాకప్ కాపీలు భద్రపరిచే ఫోల్డర్ |
